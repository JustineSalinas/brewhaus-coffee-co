# Brewhaus Coffee Co.

Online storefront for a small-batch coffee roastery, built with React, Vite, Tailwind CSS, and shadcn/ui.

## Stack

- React + Vite
- React Router
- Tailwind CSS v4
- shadcn/ui (Base UI)
- lucide-react icons

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Features

- Home, Shop, Product, About, and Contact pages
- Mobile-first responsive layout
- "Brewbot" chat widget with canned FAQ responses
- Accessible image placeholders, skip-to-content link, and keyboard-friendly nav
